Project Guide & Evaluator Reference Note

This platform is engineered for academic rigour, modular adaptability, and practical hardware deployment. Based on evaluation metrics, hardware constraints, and clinical benchmarking, the underlying modules adapt flexibly:

  • Model Interchangeability: The data pipeline conforms to standard LLaVA / ShareGPT format, enabling zero-code swapping between Qwen2-VL-2B, Qwen2-VL-7B, and LLaVA-1.5-7B.
  • Resource-Conscious Training: Uses 4-bit NormalFloat (NF4) quantization and gradient checkpointing so training runs comfortably on 6 GB consumer laptops without cloud expense.
  • Automated Self-Updating Infrastructure: The background scanner continuously inspects directory changes, automatically verifying dataset splits, generated weights, and clinical reports without manual configuration.
